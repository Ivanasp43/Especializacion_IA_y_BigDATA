# 🚀 Extractor de Datos Estructurados (Llama-3.2-1B)

Este proyecto consiste en el **Fine-Tuning** del modelo Llama-3.2-1B utilizando la técnica **QLoRA** para la transformación de Lenguaje Natural a objetos JSON.

## 🔗 Acceso al Modelo
El modelo entrenado, junto con sus adaptadores y documentación técnica detallada, está publicado y disponible para su uso en Hugging Face:

👉 **[Ver modelo en Hugging Face](https://huggingface.co/ivanasp/Llama-3.2-1B-JSON-Extractor)**

## 📋 Resumen del Proyecto
- **Tecnología:** Llama-3.2-1B / QLoRA
- **Objetivo:** Extraer entidades (producto, precio, categoría) de frases informales.
- **Entorno:** Google Colab (GPU NVIDIA Tesla T4)

*Para más detalles sobre la implementación y los hiperparámetros utilizados, consulte la Memoria Técnica adjunta en este repositorio.*
