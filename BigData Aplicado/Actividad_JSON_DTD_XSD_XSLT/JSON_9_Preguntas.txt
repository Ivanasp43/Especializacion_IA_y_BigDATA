Preguntas:


a. ¿Qué crees que representan los datos? Explica detalladamente cómo están organizados.


Los datos representan el resultado de una búsqueda de imágenes.
Organización Detallada:

1- ResultSet (Objeto Raíz): Contiene la información global de la búsqueda.

	- Metadatos de la Búsqueda: Los campos totalResultsAvailable, totalResultsReturned, y firstResultPosition 
	indican cuántos resultados totales existen, cuántos se muestran en este conjunto, y a partir de qué posición 
	empieza el conjunto.

	- Resultados Específicos: El campo Result es un array que almacena la lista de las imágenes encontradas.

2- Result (Array de Resultados): Es un vector de objetos, donde cada objeto representa una imagen individual.

	- Información de la Imagen: Cada objeto Result almacena datos como Title, Summary (una descripción o contexto
	 de la imagen), Url (la ubicación directa de la imagen), ClickUrl y RefererUrl (la fuente o página web que enlaza
	 a la imagen).

	- Metadatos Técnicos: También incluye metadatos como FileSize (tamaño en bytes), FileFormat (tipo de archivo), 
	Height y Width (dimensiones en 	píxeles).

	- Thumbnail (Objeto Anidado): Este es un objeto dentro de cada 	Result que contiene la URL y las dimensiones 
	(Height, Width) de la vista previa o 	miniatura de la imagen.


b. ¿Cuántos vectores o arrays hay definidos en este fragmento de código? ¿Qué almacena cada posición del vector?

Hay dos vectores o arrays definidos en este fragmento de código:

1- Result: Es el array principal que está dentro del objeto ResultSet.

	- ¿Qué almacena?: Almacena una colección de objetos, donde cada objeto representa la información completa de una 
	imagen individual que coincide con la búsqueda. En este caso, almacena 2 objetos (los dos resultados de la búsqueda).

2- El array implícito de ResultSet (la colección raíz): Aunque no tiene un nombre de clave explícito como Result, el objeto 
ResultSet puede considerarse la primera posición de un array de resultados si la búsqueda permitiera múltiples conjuntos. 
Sin embargo, en el contexto estricto de arrays definidos por corchetes []: solo está definido explícitamente el array Result.

1- Hay 3 atributos que son estrictamente numéricos (sin comillas) en la parte superior (ResultSet): totalResultsReturned, 
firstResultPosition. Además, hay dos instancias de FileSize numéricas dentro de cada objeto Result, sumando un total de

d. Minificar un archivo JSON consiste en eliminar saltos de línea, tabulaciones, espacios innecesarios etc. 
buscando que el archivo resultante ocupe menos espacio y sea más fácilmenteinterpretable por un computador. 
Existen herramientas web que, dado un archivo JSON, permiten obtener su representación minificada como 
http://www.webtoolkitonline.com/jsonminifier. html o http://www.httputility.net/json-minifier.aspx. Entrar 
en alguna de estas páginas para obtener la representación minificada del archivo JSON y describir qué cambios 
se han 	producido.


Al utilizar una herramienta de minificación, los principales cambios que se producen son:

1- Eliminación de saltos de línea: Todo el código se coloca en una sola línea.

2- Eliminación de espacios y tabulaciones: Se eliminan todos los espacios y tabulaciones utilizados para la indentación y la legibilidad humana. Solo se conservan los espacios estrictamente necesarios (por ejemplo, dentro de los valores de las cadenas de texto, como los títulos o summaries).
